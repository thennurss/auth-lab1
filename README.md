# Форма регистрации и авторизации (Flask)

## Запуск

```bash
pip install flask
python app.py
```

Открыть: http://127.0.0.1:5000

## Учётные записи (создаются при первом запуске)

| Роль  | Логин | Пароль     |
|-------|-------|------------|
| user  | user  | User123!   |
| admin | admin | Admin123!  |

Новые пользователи, зарегистрированные через форму, всегда получают роль `user`.

## Что реализовано

- Регистрация с проверкой логина и пароля
- Вход / выход, сессии
- Пароли хранятся в виде хеша (werkzeug, scrypt/pbkdf2), не в открытом виде
- Две роли: `user` и `admin`
- Страница `/admin` доступна только администратору (для остальных — 403)
- CSRF-токен во всех POST-формах
- База данных SQLite (`users.db`)

## Для следующей лабораторной

Роль хранится в столбце `users.role`, проверка прав — в декораторах
`login_required` и `admin_required` в `app.py`. Сюда удобно добавлять
настройку прав доступа для пользовательской учётки.
